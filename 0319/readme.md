# 🐧 유닉스(Unix) 파일 명령어 핵심 정리

유닉스 및 리눅스 시스템 환경에서 가장 빈번하게 사용되는 파일 관리 및 탐색 명령어 핵심 요약 가이드입니다.

---

## 1. 탐색 및 위치 확인 (Navigation & Location)

| 명령어 | 주요 기능 | 설명 |
| :--- | :--- | :--- |
| **`pwd`** | *Print Working Directory* | 현재 작업 중인 디렉토리의 절대 경로를 출력합니다. |
| **`ls`** | *List* | 현재 디렉토리 내의 파일 및 폴더 목록을 나열합니다. |
| **`ls -l`** | *Long Format* | 파일 권한, 소유자, 크기, 수정 날짜 등 상세 정보를 포함하여 나열합니다. |
| **`ls -a`** | *All* | 마침표(`.`)로 시작하는 숨김 파일을 포함하여 모든 항목을 표시합니다. |
| **`cd [디렉토리]`** | *Change Directory* | 지정한 디렉토리로 이동합니다. |

### 💡 cd 명령어 활용 팁
* `cd ..` : 한 단계 위의 부모 디렉토리로 이동
* `cd ~` : 사용자의 홈(Home) 디렉토리로 즉시 이동
* `cd -` : 이전 작업 디렉토리로 되돌아가기

## 2. 파일 및 디렉토리 관리 (Management)

| 명령어 | 주요 기능 | 설명 및 주의사항 |
| :--- | :--- | :--- |
| **`mkdir [이름]`** | *Make Directory* | 새로운 디렉토리(폴더)를 생성합니다.<br>`-p` 옵션 사용 시 하위 디렉토리까지 한 번에 생성 가능합니다. |
| **`touch [파일명]`** | *Touch* | 내용이 없는 빈 파일을 생성하거나, 기존 파일의 최근 수정 시간을 현재 시각으로 업데이트합니다. |
| **`cp [소스] [대상]`** | *Copy* | 파일이나 디렉토리를 복사합니다.<br>⚠️ **디렉토리 복사 시:** 폴더 전체를 복사하려면 `-r` (Recursive) 옵션이 필수입니다. |
| **`mv [소스] [대상]`** | *Move* | 파일을 다른 경로로 **이동**하거나, 파일의 **이름을 변경**할 때 사용합니다. |
| **`rm [파일명]`** | *Remove* | 파일이나 디렉토리를 완전히 삭제합니다.<br>⚠️ 유닉스에서는 삭제 시 휴지통을 거치지 않고 즉시 영구 삭제되므로 주의가 필요합니다. |

### ⚠️ 위험 명령어 안내
* **`rm -rf [디렉토리]`**: 확인 메시지 없이 디렉토리와 그 하위 내용을 강제로 모두 삭제합니다. 실행 전 경로를 반드시 확인하세요.

## 3. 파일 내용 조회 및 검색 (View & Search)

### 📄 파일 내용 조회
* **`cat [파일명]`** (*Concatenate*): 파일의 전체 내용을 터미널 화면에 연속으로 출력합니다. (짧은 파일 확인용)
* **`less` / `more`**: 내용이 긴 파일을 페이지 단위로 화면에 끊어서 보여줍니다. (더 풍부한 이동 기능을 지원하는 `less` 사용을 권장합니다.)
* **`head [파일명]`**: 파일의 앞부분 10줄을 출력합니다.
* **`tail [파일명]`**: 파일의 뒷부분 10줄을 출력합니다.
    * 💡 **핵심 옵션 (`tail -f`):** 파일에 실시간으로 추가되는 내용을 지속적으로 모니터링합니다. 주로 시스템 로그 파일(Log tracking)을 모니터링할 때 필수적으로 사용됩니다.

### 🔍 파일 내 문자열 검색
* **`grep [패턴] [파일명]`**
    * 파일 내부에서 특정 문자열(단어)을 찾아 해당 문자열이 포함된 라인만 필터링하여 출력합니다.
    * *예시:* `grep "Java" study.txt` ➡️ `study.txt` 파일에서 "Java"가 포함된 모든 줄을 찾아 출력
