# 파일 시스템 구조: i-node와 데이터 블록

이 문서는 파일 시스템에서 파일의 정보와 실제 데이터를 관리하는 핵심 자료구조인 **i-node**와 **데이터 블록**, 그리고 파일 크기에 따른 **블록 할당 및 포인터 방식**에 대해 설명합니다.

---

## 1. i-node (Index Node / 아이노드)
파일의 **메타데이터(정보)**와 실제 데이터가 저장된 물리적 위치(**데이터 블록 주소**)를 관리하는 핵심 자료구조입니다.

* **필수 할당**: 파일 시스템 내에서 파일이 하나 생성될 때마다 무조건 1개의 고유한 i-node가 할당됩니다.
* **포함하는 메타데이터 정보**:
  * 파일 크기
  * 파일 소유자
  * 접근 권한 (rwx)
  * 타임스탬프 (생성, 수정 시간 등)
  * 링크 수 (하드 링크 수)
  * 데이터 블록 위치를 가리키는 주소 포인터

---

## 2. 데이터 블록 (Data Block)
파일의 실제 내용(텍스트, 바이너리 데이터 등)이 물리적으로 기록되는 저장 공간입니다.

* **동적 할당**: 파일 내부에 아무런 내용이 없는 빈 파일이라면, i-node만 존재하고 데이터 블록은 아예 할당되지 않을 수 있습니다.
* **분할 저장**: 저장하려는 파일의 크기가 1개 데이터 블록의 기본 용량을 초과하면, 넘어가는 크기만큼 필요한 용량의 데이터 블록이 여러 개로 쪼개어 추가 할당됩니다.

---

## 3. 파일 크기에 따른 블록 할당 구조 (포인터 방식)
파일 시스템은 파일의 크기가 커짐에 따라 효율적인 데이터 관리를 위해 접근 방식을 **직접 블록 → 간접 블록 → 이중 간접 블록** 순으로 단계적으로
