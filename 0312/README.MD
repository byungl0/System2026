## 1. Linux 기본 개념

* Linux는 **다중 사용자(Multi-user), 다중 작업(Multi-tasking)** 운영체제이다.
* 모든 것은 **파일(File)**로 관리된다.
* 시스템은 하나의 루트 디렉터리(`/`)를 기준으로 모든 파일이 연결되는 **계층적인 디렉터리 구조**를 가진다.

---

## 2. 디렉터리 구조 및 경로 (Path)

### 📂 경로를 나타내는 특수 기호
* `.`: **현재 디렉터리** (예: `./script.sh` -> 현재 폴더의 스크립트 실행)
* `..`: **부모 디렉터리** (현재 위치에서 한 단계 상위 폴더)
* `~`: **홈(Home) 디렉터리** (사용자의 기본 개인 작업 공간)
* `/`: **루트(Root) 디렉터리** (리눅스 파일 시스템의 최상위 경로)

### 📍 절대 경로 vs 상대 경로
* **절대 경로 (Absolute Path)**: `/`부터 시작하는 전체 경로 (예: `/home/user/file.txt`)
* **상대 경로 (Relative Path)**: 현재 위치를 기준으로 하는 경로 (예: `../file.txt`)
